# 📊 Dashboard de Vendas | Power BI

Projeto desenvolvido durante o **curso introdutório de Power BI da Voitto**, com o objetivo de praticar conceitos de Business Intelligence, análise de dados e visualização de informações.

## 🎯 Objetivo

Construir um dashboard de vendas capaz de apresentar, de forma visual e objetiva, os principais indicadores e análises comerciais do conjunto de dados utilizado no projeto.

## 📌 Principais indicadores

- **Faturamento total:** R$ 1,38 Mi
- **Lucro total:** R$ 164 Mil
- **Quantidade de pedidos:** 1.536

## 🔎 Análises desenvolvidas

O dashboard apresenta diferentes perspectivas da operação de vendas:

- Evolução do faturamento ao longo dos meses;
- Faturamento e desempenho por vendedor;
- Análise por cliente;
- Relação entre faturamento e quantidade de pedidos por produto;
- Distribuição do faturamento por estado;
- Faturamento por setor.

## 🛠️ Ferramentas e conhecimentos aplicados

- Power BI
- Power Query
- Tratamento e organização de dados
- Criação de indicadores (KPIs)
- Visualização de dados
- Construção de dashboard
- Análise de desempenho comercial

## 📚 Sobre o projeto

Este foi um projeto desenvolvido como parte da minha jornada inicial de aprendizado em **Power BI e análise de dados**.

A proposta foi transformar dados de vendas em informações visuais que facilitassem a interpretação dos resultados e a identificação de diferentes perspectivas do negócio.

O projeto também foi uma oportunidade para praticar a organização de um dashboard, a escolha de visualizações e a apresentação de indicadores de forma mais clara e objetiva.
